# Simple CV / Resume Card

A clean, responsive and aesthetic personal CV/Resume webpage created as **Task 2 for the SpireX Foundation Web Development Internship**.

## ✨ Project Overview

This project is a personal online resume designed to present my:

* About Me
* Education
* Technical Skills
* Internship Experience
* Projects
* Interests
* Contact Information

The website uses a modern **navy blue, maroon and beige** color palette with a responsive layout suitable for desktop, tablet and mobile devices.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* GitHub Pages

## 🎨 Features

* Responsive CV/resume design
* Modern navy, maroon and beige color scheme
* About Me section
* Education timeline
* Skills cards
* Internship experience section
* Featured projects
* Contact section
* GitHub and portfolio links
* Dark/Light mode toggle
* Smooth navigation
* Hover animations
* Mobile-friendly layout
* Automatic copyright year using JavaScript
